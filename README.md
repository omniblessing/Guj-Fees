# Gujarat PG Medical Fees

A simple, searchable directory of postgraduate medical college fees across Gujarat.

## About

This website makes it easier for NEET-PG aspirants to find and compare PG medical college fees without having to search through lengthy PDF documents.

You can search and filter fee details by:

- College
- Specialty
- Course (MD / MS / Diploma)
- Government Quota (GQ)
- Management Quota (MQ)
- Annual Fee
- Term Fee

The directory is designed to be lightweight, fast, and easy to use on desktop, tablet, and mobile devices.

## Features

- 🔎 Fast college and specialty search
- 🎓 Government & Management quota filters
- 💰 Annual and term fee information
- ↕️ Sort fees from low to high or high to low
- 📱 Mobile-friendly responsive design
- ⚡ Lightweight static website
- 🚫 No login or account required
- 🌐 Can be hosted using GitHub Pages

## Data Source

The fee information has been compiled from the supplied Gujarat PG medical fee document:

`GUJ PG FEES 25.pdf`

The website presents the information in a searchable format for convenience.

## Important

Fee structures may change between admission cycles. Always verify the applicable fees with the relevant official Gujarat admission/fee authority before making an admission or financial decision.

This website is intended for **informational and decision-support purposes only** and is not an official government admission portal.
